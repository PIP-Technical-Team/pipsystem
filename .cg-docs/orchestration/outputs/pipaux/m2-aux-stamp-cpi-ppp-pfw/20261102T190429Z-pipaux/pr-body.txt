## Summary

Implements M2 Phase 2 Step 4, `save-cpi-ppp-and-pfw-through-stamp`, for the three skeleton auxiliary series only.

- Validate and persist the CPI long key: `country_code, year, survey_acronym, reporting_level, cpi_year`, including validation after reshaping.
- Persist the PPP key: `country_code, reporting_level, ppp_year, release_version, adaptation_version`, and update default flags deterministically when a vintage is added.
- Reconcile PFW validation and persistence on `country_code, surveyid_year, welfare_type, is_alt_welf`.
- Save through `pip_aux_save()` -> `pipload::pip_write()` -> `stamp::st_save()` with source metadata and generator code hashes. Data-neutral raw SHA changes do not create extra content versions, and skipped saves return usable retained version pins.
- Run storage tests in disposable R processes rather than mutating private stamp state. Qualify the eight skeleton uniqueness predicates as `assertr::is_uniq()` so validation works in the installed package as well as under source loading.
