---
title: "pipsystem"
---

Local review site for the PIP incremental build system. Every page under
`gen/` is generated by `tools\pipsys\pipsys.cmd site` (or `/pip-site`) from
the files in pipsystem and the package repositories; edit the sources, not
the pages. The site is not published.

- [Overview](gen/overview.md): one row per package and the roadmap summary.
- [Handoffs](gen/handoffs.md): latest run per task.
- [Roadmap](gen/roadmap.md): every milestone and feature.
- [Pipeline map](gen/map.qmd): stages and links from `tables/pipeline_map.csv`,
  one cited claim per row (evidence only, not a contract).
- [System design](gen/design.md): `SYSTEM_DESIGN.md`.
- Status pages and Plans: see the sidebar (`gen/status`, `gen/plans`).

Generated report times (overview, handoffs, status pages) are New York time
(EDT or EST). Dates and times inside copied Plans and the design page stay as
originally recorded, often UTC. Links inside copied pages open the source file
on disk.
