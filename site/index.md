::: {.callout-note}
## Generated Content Boundary

Every page under `gen/` is generated by `tools\pipsys\pipsys.cmd site` (or `/pip-site`) from the files in `pipsystem` and the package repositories; edit the sources, not the generated pages. The site is local-only and is not published.
:::

::: {.callout-tip}
## Timestamps and Local Source Links

Generated report times and assessment times are shown separately in New York time (`EDT` or `EST`). A rebuild refreshes the snapshot, not the assessment's evidence. Run `/pip-next` to reassess the next development action, then `/pip-site` to display it. Dates inside copied Plans stay as recorded. Source links open local files.
:::
