::: {.callout-note}
## Generated Content Boundary

Every page under `gen/` is generated by `tools\pipsys\pipsys.cmd site` (or `/pip-site`) from the files in `pipsystem` and the package repositories; edit the sources, not the generated pages. The site is local-only and is not published.
:::

::: {.callout-tip}
## Timestamps and Local Source Links

Generated report times (overview, handoffs, status pages) are formatted in New York time (`EDT` or `EST`). Dates and times inside copied Plans and the design page stay as originally recorded, often `UTC`. Relative links inside copied pages are rewritten to `file:///` URLs that open the source file on disk.
:::
